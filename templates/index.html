О приложении

Управляйте новогодним настроением прямо со своего смартфона!

«Елка» — это интерактивное приложение, созданное на Unity для беспроводного контроля вашей гирлянды через точку доступа POV_Tree_WiFi.

Боковые функции устройства

  • ✨
    Режимы анимации

    «Неоновый саморез», «Дождь матрицы», «3D Гиперкуб», «Огненный смерч» и др.

  • 🎨
    Смена палитры

    Быстрый выбор предустановленных цветовых схем для праздничного сияния.

  • 🎛
    Авторский цвет

    Удобный HSV/RGB кастомизатор для точной ручной настройки каждого оттенка.

  • 💡
    Яркость Ёлки

    Плавный слайдер для настройки комфортного уровня освещения в комнате.
